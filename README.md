# Northwest Security & Lock Website

Professional multi-page website for Northwest Security & Lock in Portland, Oregon.

Built for local SEO, online service requests, and lead capture.

## Current pages
- `index.html` — homepage built around calls, service categories, SEO, and lead capture
- `online-booking.html` — online service request form
- `lead-dashboard.html` — demo lead dashboard using browser storage
- `emergency-locksmith.html` — emergency locksmith landing page
- `contact.html` — contact page with lead capture form
- `services/automotive-locksmith.html` — automotive locksmith page with full service list
- `services/residential-locksmith.html` — residential locksmith page with full service list
- `services/commercial-locksmith.html` — commercial locksmith page with full service list
- `service-area/portland-locksmith.html` — Portland local SEO page
- `SHOT_LIST.md` — photo/video list for the website shoot
